# Cost split: registration

Plan hash `fae0101feb37af11`, committed before the run. A descriptive re-analysis, not a hypothesis test: it takes the SAME trades as PRs #101 and #102 (and the EMA strategy on #101's two windows) and splits each trade's net R into gross, taker fees, slippage and funding, counts exit reasons and measures the stop distance per pair. No trade is added or removed, nothing is tuned, no window is opened that has not been read. Costs are the studies' own: 5 bps taker per side, 5.5 bps slippage per side (11 round trip), historical funding. Sources pinned in the hash: `cost_split.py`, `entry_study.py`, `profit_backtest_dr.py`, `profit_backtest.py`, `shortframe_backtest.py`, `donchian.py`, `rsi_mr.py`, `indicators.py`, `strategy.py`, `reporting.py`, `research/bootstrap.py`, `research/archive.py`, `research/funding_archive.py`.
Windows: A = 2020-04-01 to 2025-01-01; B = 2025-01-04 to 2025-11-01 (the 10 months read once by #101); C = the nine 182-day test windows of #102 (2022-04 to 2026-09), unfiltered.
